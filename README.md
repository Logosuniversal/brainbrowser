# Brainlight · 视觉脑图谱

本包为可独立运行的视觉演示，包含全部模型、脚本、样式及完整参考文献。
保留面孔、文字、视觉运动、场景四类视觉内容，没有听觉、触觉或动作演示。
另含「信息过载」研究专题：五组机制、原图纠偏、14 篇研究与综述，以及视觉分类体验。
首页点击「信息过载 · 研究专题」或打开 overload.html；完整笔记见 information-overload-research.md。

## Windows

1. 解压整个文件夹（不要在 ZIP 内直接打开网页）。
2. 需要已安装 Python 3。在解压后的文件夹打开 PowerShell，执行：

   py start.py

3. 浏览器会自动打开。保持命令窗口运行；结束时按 Ctrl+C。

macOS / Linux 可执行 `python3 start.py`。端口被占用时使用 `--port 8001`。
只绑定本机地址，不需要 npm、不需要下载模型、不连接外部模型或字体服务。
文献的 DOI 外链需要网络。浏览器需要 WebGL；不能直接双击 index.html。

## 操作

拖动旋转、滚轮缩放；顶部切换视角、脑叶颜色、透明度和标签。
脑区、标签与按钮使用一致色标；透视时表面色块及轮廓变透明，内部皮层保留颜色以方便定位。
左侧选择视觉场景并播放，底部控制进度和速度。
点击脑区或标签查看说明、定位、切换半球，或展开对应论文引用。

## 依据与范围

页面内含六篇具名论文的标题、作者、年份、DOI 及所支持的具体发现。
信息过载专题另外区分研究发现、理论解释及适用边界；体验只记录本轮正确率和反应时间。
皮层表面与解剖标签来自 BrainBrowser 示例，模型不是截图原始模型。
解剖分区只能提供空间参照，不等同于 FFA、VWFA、MT/V5、PPA 的功能边界。
动画是讲解顺序，不表示测量到的神经时序、活动幅值或纤维通路。
本模型不包含视网膜、丘脑、小脑等皮层外结构。
视觉篇文献依据经典来源整理；信息过载篇已核对 14 篇元数据、阅读 12 篇摘要。
尚未逐篇阅读全文，详细核验范围见 information-overload-research.md。
